# FastAPI + HTMX + Jinja2 + Tabler

Одна страница с 45+ примерами Tabler: таблица, формы, графики, вкладки,
модальные окна, уведомления, календарь, карусель, светлая и тёмная темы.

## Запуск

Нужны установленный **uv** и **Python 3.11–3.14**.

```bash
uv sync --locked --no-dev
uv run --locked --no-dev uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Открыть [localhost:8000](http://127.0.0.1:8000/). Остановить: `Ctrl+C`.
На Linux/macOS можно запустить `./run.sh`; другой порт: `PORT=8001 ./run.sh`.

Python-пакеты устанавливаются только из **PyPI**. Автоматическая загрузка Python
отключена. Все CSS/JS уже включены в `app/static/vendor`; Node.js и npm не нужны.
После установки приложение работает без внешней сети.

## Проверки

```bash
uv sync --locked
uv run --locked pytest -q
```

## Структура

- `app/main.py` — FastAPI, SQLite, HTMX-фрагменты, CSV.
- `app/templates/` — Jinja2: страница, макросы, фрагменты.
- `app/static/` — локальные стили, скрипты, SVG и библиотеки.
- `tests/` — проверки приложения.
- `uv.lock` — зафиксированные зависимости.

Проекты сохраняются в `data/demo.sqlite3` (не попадает в Git).
Путь можно изменить переменной `TABLER_DB`.
Тема и задачи сохраняются в браузере. Графики и лента — демонстрационные;
дата и теги не сохраняются. Выбор файлов остаётся локальным.
Приложение предназначено для локального использования, авторизации нет.

Библиотеки и лицензии: [THIRD_PARTY.md](THIRD_PARTY.md).
